# AI 开始做梦了？

> 冒个泡儿

## 一个标题撞上另一个标题

2026年11月6日，Anthropic 工程博客登了一篇文章，标题是《The components of agent memory》，讲 Claude 如何「做梦」：空闲时回放记录，整理所学，纠正错误，下次找得更快（Anthropic 工程博客，2026-11-06）。

同一个词，五十八年前就印在了一本书的封面上。菲利普·迪克，《仿生人会梦见电子羊吗？》，1968年（菲利普·迪克，1968）。

## 先往回走

两千三百年前，庄子梦见自己是蝴蝶，醒来问（庄子《齐物论》）：

昔者莊周夢為蝴蝶，栩栩然蝴蝶也，自喻適志與！不知周也。俄然覺，則蘧蘧然周也。不知周之夢為蝴蝶與，蝴蝶之夢為周與？

庄子不问梦真不真。真假是第二问，第一问是做梦的那个「我」站不站得住。

古人还给梦留了两个坐标：地方和时间。地方是记忆宫殿，源头是一场塌掉的宴会：希腊诗人西蒙尼德斯赴宴时被叫出门，屋顶随即塌下，宾客面目全非，他凭每个人坐的位置一一认出尸身（西塞罗《论演说家》）。罗马修辞手册把这办法写成一句定义："The artificial memory consists of places and images."（人工记忆由地方和意象构成。《论赫伦尼乌斯的修辞术》，约公元前90年。）

时间是黄粱一梦和烂柯一梦。卢生一觉醒来：「盧生欠伸而悟，見其身方偃於邸舍，呂翁坐其傍，主人蒸黍未熟，觸類如故。」吕翁只回一句：「人生之適，亦如是矣。」（沈既济《枕中记》。）王质看完一盘棋：「質起，視斧柯爛盡，既歸，無復時人。」（任昉《述异记》。）梦里的时间，和醒着的时间，不是一个流速。

## 回到二十世纪

1950年，图灵把「机器会不会思考」换成了一个游戏：藏在帘子后面说话，分不出来是人是机，就算过关（Alan Turing，1950）。图灵不问机器里面有没有东西，只看外面像不像。

PKD 把这个游戏翻了个版。小说里分辨仿生人和真人，靠 Voigt-Kampff 测试：不问数学，不问逻辑，只问一些会引起共情反应的场景，再测身体的反应。仿生人答得出来，但身体不会先动。书里有一句分界："Empathy, evidently, existed only within the human community, whereas intelligence to some degree could be found throughout every phylum and order including the arachnida."（共情显然只存在于人类共同体之中，而智能在某种程度上遍布各个门类，甚至蛛形纲。）测的不是像不像人，是会不会动容。会不会做梦，等于有没有心。有没有心，不看它说什么，看它为别人的痛动不动容。

## 再回到现在

今天的生成式 AI，底下是一次概率计算：算下一个词最可能是什么。可它算出来的东西，读起来像意思。问题就卡在这里：概率算出来的，是语言，还是意思？是复述，还是做梦？

Anthropic 的回答是整理。它的「做梦」没有梦境，只有整理：回放白天的记录，合并重复的，纠正记错的，补上缺的索引。醒来时东西还在，找得更快。它给机器建的 wiki，就是一座记忆宫殿，每个要点有自己的位置。记忆这件事，从古到今，靠的都是地方。

## 梦到底是什么？

词借过来了，意思只借了一半。人的梦有画面，有情绪，有醒来就忘的荒唐。机器的梦只有条目、索引和纠错。名字相同，做的事不同。

机器做梦，做的不是梦，是记忆的家务。

庄子问的是人，图灵和迪克问的是机器，Anthropic 问的还是机器。两千三百年，问题没变，变的只是做梦的主语，和梦里的时间。

剩下一个问题：梦到底是什么？
