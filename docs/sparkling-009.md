# 搬家

> 冒个泡儿

以前换一台新设备，要做的事很具体：装 APP，记密码。装完，设备就是你的了。

现在不一样了。每台设备都有自己的 AI agent。换设备，装 APP 还是要装，密码还是要记，但真正要搬的东西变了：搬的是 agent 的身份。

身份有三样。Profile：你是谁，你的设备怎么分工，你喜欢什么、不要什么。Skill：它会什么，能替你干哪些活。Soul：它怎么说话，信什么，遇到不知道的事是猜还是问。

这次搬家是真的。前几天我把 iPad Pro 换成了 OPPO Pad Mini，不想再被一家生态绑着。装 APP、记密码还是要做，但那不是搬家。真正的搬家，是让新设备上的 agent 入职——profile、skill、soul 三样，一样一样搬过去。设备换了，agent 的身份搬过来了，这才叫搬完了。

这三样，以后就是换设备的协议。就像以前搬家搬的是家具，以后搬家搬的是人。

但有两件事要小心。

第一，协议只有大家都认才叫协议。如果每家都自己定一套，应用锁定就变成了 agent 锁定，换汤不换药。真正的协议得是厂商中立的，就像 OPML 之于订阅、Markdown 之于文本。

第二，soul 是最难搬的。Profile 和 skill 是清单，可以复制；soul 是性格，写成文档能搬过去，但 agent 的表现是模型加文档长出来的，搬文档不等于搬灵魂。记忆也一样，搬得越多，泄露得越多。

花园的力量在于让你出不去。一个能带走的 agent 协议，让出去变得便宜。墙还在，但门已经有了。

你换设备的时候，搬的是什么？
