# 酝酿 Brewing

> 一夕运粮，一期酝酿。

## 这是什么

一份产业与认知周刊，每周五从本周的收藏里酿出十条：农牧产业链、五维健康前沿、认知方法论与人机协作。只放原始链接＋一句话点评，不转载正文。

## 为什么叫"酝酿"

南京有一条运粮河，相传明太祖朱元璋为从东郊运粮至城内而开凿（《南京历代运河》），清代《同治上江两县志》载其"阔三丈，深五尺"。

运粮是一夕的事，酝酿是一期的事——每晚收集的粮，每周酿成一期。

不入运粮，不如酝酿。

（brew 谐音三兄弟：不入、步入、不如——说的都是同一件事：先运粮，再酝酿。）

## 栏目

- **本周主题**：当周最具结构性、跨越周期的核心事件
- **农牧产业**：猪周期、产能存栏、饲料原料、生物添加剂与发酵工程
- **五维健康**：睡眠节律、心率变异性(HRV)、代谢、微生态与营养干预前沿
- **工具与方法**：认知科学、系统思考、人机协作与产业研究实践
- **随机一条**：文史哲、思想家或读书划线

栏目可缺，不硬凑。每期约 10 条是上限。
